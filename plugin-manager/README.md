# 大雄插件管理桌面版

## 安装

1. 下载 `大雄插件管理.exe`。
2. 把它复制到“大雄无限画布”的主目录。
3. 确保它与 `大雄无限画布.exe`、`plugin_host.py`、`plugins/` 位于同一目录。
4. 双击运行。

不要直接在浏览器下载目录或临时下载目录中运行，否则程序无法找到大雄无限画布后台。

## 功能

- 启用、停用、安装、升级和卸载插件。
- 启动时自动检查 GitHub 插件仓库。
- 显示本地版本和最新版本。
- 一键下载并升级插件。
- 下载后校验体积、SHA-256、插件 ID、版本和核心兼容性。
- 默认保留 `plugin-data/` 中的插件数据。

## 源码与构建

源码位于 `source/PluginManagerApp.cs`。在 Windows 上运行 `build.ps1` 即可重新编译，生成文件位于当前目录的 `大雄插件管理.exe`。
