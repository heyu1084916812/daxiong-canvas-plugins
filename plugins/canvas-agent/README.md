# Canvas Agent 2.2.49

AI Agent 插件（普通画布 + 智能画布）。

## 本版本重点（2.2.49）
- 修复无上传参考图时，阶段2把同计划前序生成结果误写成 `attachment_indices` 并触发索引越界的问题
- 明确支持“先生成 Logo、三视图、包装，再以三张成功结果同时生成主图和详情页”的两批执行链
- Skill 逐页原文绑定扩展到 Logo、三视图、包装等非主图/详情页成果，不再只处理 `main/detail`
- 兼容“第1页”“第1步”“第1张”和“1.”等 Skill 页面标题格式
- 修复 Skill 策划正文完整、但因缺少三个固定全局标题而被误判为“策划内容不完整”的问题
- `AGENT_TASK_SPEC.global_contract` 逐字保留视觉定位、统一风格和统一负面提示词，并无损绑定到每个页面生成步骤
- 修复智能画布选图后“发送至设计大师”因点击过程清空选区而报“没有选中的图片节点”的问题
- 发送按钮在按下前冻结图片选区，且 Agent 交互区不再被智能画布当作空白点击
- 启用 Skill 时，阶段2逐页原样绑定阶段1策划内容，完整保留页面作用、画面内容、版式结构、文案和排版说明，不再压缩成短提示词
- 执行层只绑定参考图、参数和依赖，最终提示词直接进入画布节点与生图请求
- 阶段1新增隐藏结构化任务单，数量、成果类型、比例和画质只确定一次并贯穿后续阶段
- 阶段2只负责生成提示词、参考图和依赖关系，不再从提示词关键词反推主图/详情页参数
- JSON fallback 保留步骤身份与参数；任务单和步骤数量不一致时明确停止，不再猜测执行
- 阶段1策划增加完整性门禁，截断的 Skill 策划不会进入下一阶段或触发生图
- 阶段2要求每个步骤显式绑定 role、ratio、resolution 和跨阶段成果
- 保存阶段成果及其输入/输出 ID，支持 Logo → 品牌色系 → 产品 → 推广图的多轮工作流
- 修复对话中明确填写的比例、1K/2K/4K 和画质被规划默认值覆盖的问题
- 用户原文参数现在最高优先，并完整锁定到画布节点与实际生图请求
- 扩展“高画质/中画质/低画质”和“9比16”等中文参数写法
- Agent 文字整体放大，提升侧栏阅读与操作清晰度
- 多个执行提示词合并为一个默认折叠区，避免多图任务拉长对话
- 空对话展示常用 Skill，可点击直接引用
- 新增图像模式：支持参考图 + 最终提示词直连生图，不经过 LLM
- 右侧可拉伸 Agent 侧栏（不改原画布源码）
- 「设为默认」同时记住平台 + 模型，下次打开优先恢复平台
- 打开侧栏更快：减少重复重绘与重毛玻璃
- 失败项重试可用：安全拦截 / moderation 失败可重新提交生图
- Skill / 需求 / 参考图：先直出内容，再理解执行

## 安装
1. 打开大雄无限画布
2. 更多设置 → 插件管理
3. 安装本 ZIP（根目录为 `canvas-agent/`）
4. 启用插件后刷新画布

## 接口
`/api/plugins/canvas-agent/`
