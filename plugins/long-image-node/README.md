# 长图节点插件 1.2.0

适用于大雄无限画布核心版本 `2026.08.04` 及以上。插件同时注入普通画布和智能画布，可在“更多设置 → 插件管理”中独立开启或关闭。

## 使用

1. 在画布中框选至少两张图片；多图节点中的图片也会按节点从上到下、从左到右的顺序收集。
2. 点击画布底部出现的“合成长图”。
3. 长图节点会按最小来源宽度生成真实 PNG，并在画布上按完整宽高比展开显示；原图片节点和原文件保持不变。
4. 双击画布上的长图，打开独立的长图编辑器。
5. 在编辑器右侧拖动组成图片，靠近条目的上半区表示插到前面，下半区表示插到后面；松手后生成新版本。
6. 画布长图右上角和编辑器标题栏均可直接下载当前完整 PNG。

编辑器支持移除来源、自定义宽度和明确允许放大小图。宽度和放大选项可连续调整，点击“重新生成”后才执行一次；拖动排序仍会自动生成。重新生成由本机 Pillow 完成像素缩放和纵向拼接，不调用 AI、模型或外部生成接口。插件会缓存未变化来源的校验结果并并行检查来源，以缩短重复生成前的等待。

画布节点外部不常驻来源列表或设置区。插件不会静默压缩、跳过来源或自动重试失败请求。

当 Canvas Agent 的“发送至设计大师”按钮同时出现时，“合成长图”会自动上移，两个操作入口不会互相遮挡。

## 停用和数据

- 关闭插件后，新接口立即停止使用；刷新画布后创建和排序入口消失。
- 已完成的长图仍以普通图片节点显示。
- `longImage` 排序和设置随画布节点保存，关闭、升级或默认卸载插件不会清除。
- 重新开启并刷新后恢复长图交互，不会自动重新生成。
