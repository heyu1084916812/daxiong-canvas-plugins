# 局部提取与图像融合插件

当前版本：`2.7.2`
最低核心版本：`2026.07.13`

本插件为普通画布和智能画布增加“提取选区”与“图像融合”流程。它采用可挂载插件系统的 schema v2 清单：启用状态由宿主的 `data/plugin-state.json` 管理，插件业务数据位于 `plugin-data/local-patch/`，不修改原项目的 `main.py`、`static/` 和 `run.bat`。

历史版本、已解决问题、技术根因和维护排查方法见：[融合节点插件-版本迭代与故障排查-v2.6.0.md](./融合节点插件-版本迭代与故障排查-v2.6.0.md)。

## 启动方式

在项目根目录运行 `start.bat`，然后可从“插件管理”启用或停用本插件；刷新普通画布或智能画布后生效。

- `start.bat`：插件模式，平时需要使用本插件时运行它。
- `run.bat`：原项目无插件模式，只用于排查或临时关闭插件。
- `http://127.0.0.1:3000/api/plugins`：查看插件版本、启用状态和兼容性。

不要同时运行 `start.bat` 和 `run.bat`，否则会争用 3000 端口。

## 普通画布使用方法

### 提取局部选区

1. 单击一个图片节点。
2. 在图片上方的统一功能栏中点击“提取选区”。也可以双击图片打开预览编辑器，再选择顶部的“提取选区”。
3. 使用原项目的裁剪框、比例、缩放和拖动功能选择区域。
4. 点击“提取选区”。插件会在原图右侧创建新的局部图片，原图不会被修改。
5. 新局部图会保存 `cropContext`。之后可继续进行多轮单图改图、2×/4×放大、并发生成、output 分组或普通分组。

### 图像融合

1. 从创建菜单添加“图像融合”节点。
2. 将完整原图连接到融合节点的“原图”端口。
3. 将一张或多张提取并处理后的局部图、output 节点或图片分组连接到“局部修改”端口。
   - 左侧连接点只接收完整原图。
   - 右侧连接点同时用于接收局部修改图，以及把融合节点的最新完整结果连接到后续图片处理节点。
4. “局部修改”端口允许保留多条连线；每条连线对应一张待融合局部图。如果某个输入节点有多张图，可在对应缩略图上用左右按钮独立选择。
5. 按需开启“颜色匹配”，点击“开始融合”。
6. 成功后，结果会通过连线生成在融合节点右侧，不覆盖任何输入图片。
7. 点击结果图进入预览，在右下角点击“对比原图”，可用滑杆比较融合前后效果。

点击画布空白区域会取消图片节点选择，并自动隐藏图片工具栏。

## 智能画布使用方法

### 提取局部选区

1. 上传图片，或选中已有的单图/多图节点；多图节点会使用当前选中的图片。
2. 点击图片节点上方功能栏中的“提取选区”。也可以双击图片进入预览编辑器，再点击顶部的“提取选区”。
3. 调整选区后确认，插件会在源节点右侧创建一个新的智能图片节点，源图不变。
4. 局部图经过连续多轮生成、编辑、2×/4×放大、并发输出、自动分组、历史分组或重新放回画布后，会继续携带上下文。

### 图像融合

1. 双击画布空白区域，在创建菜单添加“图像融合”。
2. 将完整原图连接到左侧“原图”端口，将一张或多张处理后的局部图连接到右侧“局部修改”端口。
   两个连接点固定在整个融合节点的左右外边缘，不会覆盖预览图片。
3. “局部修改”端口支持多条连线；output 或分组包含多张图时，每条连线都可在融合节点内独立切换选择。
4. 点击“开始融合”。结果会通过连线生成在节点右侧。
5. 点击融合结果进入预览，使用右下角原项目自带的“对比原图”按钮查看滑杆对比。
6. 图像融合节点支持自由拉宽、拉高和同时缩放；为避免控件重叠，最小安全尺寸为 `230×280`，内部预览、状态和按钮会随节点尺寸自适应，连线始终吸附到左右端口中心。

## 上下文保留规则

- 上下文会同时保存在图片节点和图片文件对象中，并按本地文件指纹登记。
- 同一张局部图经过多轮单图处理、并发生成、output、分组、复制粘贴、保存刷新、导入导出或重新拖入画布时，会尽量恢复同一个上下文。
- 多个输入具有完全相同的上下文时，输出继续继承。
- 多个不同上下文混合时，输出会标记冲突，融合节点会阻止执行，避免把局部图融合回错误的原图。
- 遮罩角色图片不会自动作为可融合局部图传播上下文。
- 融合完成后的全图会写入“完整图边界”标记并清除局部上下文。它可以作为新原图再次提取另一个选区、继续改图和融合，不会追溯到上一轮局部图。
- 同一张原图提取的多个不同选区可以作为多条独立局部连线一次融合；重叠区域按融合节点中连线顺序处理，后连接的结果覆盖在前面。

## 使用限制

- 每次提取仍为单个矩形选区，但一个融合节点最多可同时融合 16 张不同选区的局部图。
- 只处理项目内 `/assets/` 或 `/output/` 图片；远程图片需要先导入本地。
- 原图以文件 SHA-256 和 EXIF 修正后的自然尺寸校验，换了原图即使外观看起来相同也可能被拒绝。
- 局部图宽高比相对提取区域变化超过 1% 时会拒绝融合；2×/4×等同比例放大可以自动缩回。
- 默认最大解码量为 100MP，可通过环境变量 `LOCAL_PATCH_MAX_PIXELS` 调整。
- 所有裁剪和融合结果都会保存为新 PNG，不覆盖输入文件。

## 常见问题

### 页面没有“提取选区”或“图像融合”

确认是通过 `start.bat` 启动，而不是 `run.bat`。访问 `/api/plugins`，检查 `local-patch` 的 `compatible`、`enabled` 和 `loaded` 是否都为 `true`。

### 提示“局部图没有上下文”

请从“提取选区”产生的局部图开始处理。不要把图片复制到项目外再作为新文件导入；如果确实需要重新导入，应保留同一文件内容，让插件可通过文件指纹恢复上下文。

### 提示“上下文冲突”

某一张“局部修改图”本身混合了多个不同上下文。多个不同选区应保持为多张独立局部图，分别连接到融合节点，不要先把它们送入同一个生成节点混合。

### 提示原图指纹或尺寸不一致

融合节点的“原图”端口不是提取时使用的原始文件。重新连接正确原图。

### 提示局部图宽高比错误

处理中改变了局部图比例，例如非等比缩放或宫格拼接。恢复原宽高比后重试。

### `start.bat` 无法启动

先关闭正在运行的 `run.bat` 或其他占用 3000 端口的程序。项目自带 Python 时会优先使用 `python/python.exe`，否则使用系统 `python`。

## 更新、迁移和卸载

- 安装或更新插件：关闭项目，把发布 ZIP 解压到原项目根目录并允许合并目录，然后运行 `start.bat`。
- 更新原项目后：插件目录一般会保留；如果 `plugin_host.py`、`plugin_runtime.py` 或 `start.bat` 被覆盖，重新解压插件包即可。
- 迁移给别人：把发布 ZIP 发给对方，对方解压到相同原项目根目录即可使用，不需要复制你的 `assets/`、`output/`、`data/` 或其他个人数据。
- 卸载单个插件：删除 `plugins/local-patch/`。如果没有安装其他共用此宿主的插件，也可以再删除 `plugin_host.py`、`plugin_runtime.py` 和 `start.bat`。
