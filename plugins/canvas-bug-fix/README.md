# 画布 Bug 修复

面向普通画布和智能画布的兼容修复插件。每类问题使用独立脚本注入，互不覆盖，方便后续单独维护或停用。

## 本版重点修复

1. 所有节点均可使用 Ctrl+C / Ctrl+V 复制粘贴，并正确区分画布节点与系统剪贴板图片。
2. 图片组内单图支持 Ctrl+C / Ctrl+V 和 Alt+拖动复制；复制保留相关连接，并可作为一次操作撤销。
3. 图片节点拖拽缩放时保持原图宽高比，普通画布与智能画布一致。
4. 解散图片组时恢复建组前每张图的原始位置、大小、比例、节点 ID、连接线和输入引用。
5. 调整输入图顺序时同步更新上传/生成节点的持久化输入顺序；兼容图片组→循环节点→上传节点链路，不再用移动左侧节点位置作为兜底。
6. 生成日志已有图片而画布缺失时自动补回；日志提供“发送到画布”按钮，重复发送会去重。

## 既有修复

- 普通画布循环仅处理真实连接节点。
- 智能画布多图循环保持图一、图二及后续输入槽位语义。
- “整理选中”点击后保持选择并执行整理。
- 智能画布工作流资产库双向传递。
- 普通画布 LLM 三个内容框可拉伸。
- 普通画布与智能画布 Alt+拖动复制、撤销及悬停光标兼容。
